# Electric Palms Events website

The website for Electric Palms Events: community events, silent discos and snail mail in Sarasota, Florida. It lives at [electricpalmsevents.com](https://electricpalmsevents.com).

## What's here

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About |
| `events.html` | Services |
| `creatives.html` | Call for Creatives |
| `snail-mail.html` | Snail mail |
| `404.html` | Shown when someone follows a broken link |

- `img/` holds the logo, icons, artwork and the image shown when the site is shared as a link.
- `robots.txt` and `sitemap.xml` help search engines find the pages.
- `.nojekyll` tells GitHub Pages to publish the files exactly as they are.

## Forms

The three forms (Work with Electric Palms, Call for Creatives, Snail mail waitlist) are Google Forms shown inside the pages. To change a question, edit the form in Google Forms. The website picks up the change by itself.

## Publishing

GitHub Pages publishes the `main` branch. A change merged into `main` is live within a few minutes.
